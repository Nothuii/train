# Goal 
The password for the next level is stored in the file data.txt, which is a hexdump of a file that has been repeatedly compressed. For this level it may be useful to create a directory under /tmp in which you can work. Use mkdir with a hard to guess directory name. Or better, use the command “mktemp -d”. Then copy the datafile using cp, and rename it using mv (read the manpages!)
# Steps 
the hint indicates that the data.txt is a hexdump of a repeatedly compressed file. First, create a temporary working directory:
mktemp -d
``` 
Output 
```bash 
/tmp/tmp.tECqLr50zf
```
I will copy the `data.txt` to the temporary directory
```bash 
cp data.txt /tmp/tmp.tECqLr50zf
```
Navigate to the directory
```bash 
cd /tmp/tmp.tECqLr50zf
```
Rename data.txt
```bash 
mv data.txt nothing 
``` 
Reverse the hexdump to restore the binary file using `xxd`
```bash 
xxd -r nothing hello
``` 
Check the file type of `hello` using the `file` command 
```bash 
file hello 
``` 
Output 
```Text 
hello: gzip compressed data
``` 
Add the `.gz` extention and decompress it
```bash 
mv hello hello.gz 
gunzip hello.gz 
``` 
Check the file type again
```bash 
file hello 
```
Output
```bash 
hello: bzip2 compressed data 
``` 
Rename with the `.bz2` extension and decompress it
```bash 
mv hello hello.bz2 
bunzip2 hello.bz2 
``` 
Repeat this process until encountering a tar archive:
``` Text
hello: POSIX tar archive (GNU)
``` 
Rename with the `.tar` extension and extract it
```bash 
mv hello hello.tar 
tar -xvf hello.tar 
``` 
Output 
```Text
data5.bin
```
Continue decompressing each layer step-by-step until obtaining plain text:
```Text 
data8: ASCII text 
```
